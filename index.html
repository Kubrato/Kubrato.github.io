What I'm working on now

Towards an agentic digitisation workflow

My MSc thesis, on the Zeri auction catalogues project. About 1,600 catalogues and 200,000 images went through a workflow in which people checked every step and decided where each catalogue went next.

The question

Can AI models, used as they are with no retraining, make those checks and routing decisions well enough to replace the human step?

What I'm doing

I'm modelling the workflow step by step, with each step's inputs, outputs and requirements. For every human check I design a few-shot, in-context agent that sees the same material and has to make the same call.

How it gets tested

The project is finished, so the human decisions and workflow logs already exist. I compare each agent decision with the catalogue structures people validated.
